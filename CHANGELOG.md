⚙️ Usage
After activation, go to Milyutin Image Opt. in the admin menu.

Choose the formats you want (WebP, AVIF, or both).

Adjust quality sliders (recommended: WebP 82, AVIF 50).

Enable auto-convert on upload for new images.

Click Run bulk conversion to process existing images.

Watch the progress bar and statistics.

❓ FAQ
Does it modify my original images?
No. The plugin only creates new .webp / .avif files next to the originals. Originals stay untouched.

What if my server doesn't support WebP or AVIF?
The plugin detects server support and shows a warning in the admin panel. Unsupported formats are simply skipped.

Can I use it with a CDN?
Yes. Since files are created on disk next to the originals, any CDN will pick them up automatically.

How do I revert changes?
Deactivate the plugin. Your original JPG/PNG files remain intact. To remove the converted files, delete them manually.
